## 2. 各里程碑详细任务与验收

### M1 工程骨架与技术验证（预计 1–2 周）

**任务**
1. 初始化 Git 仓库；按 04 §2.2 模块化 Gradle 结构；冻结版本目录（`libs.versions.toml`，对照 04 §1.2 核对清单）。
2. 建立 `core:speech` / `core:llm`：OpenAI 兼容 SSE 客户端；**当前默认** MiMo ASR/TTS（`MimoAsrEngine` / `MimoTtsEngine`），系统 SpeechRecognizer 仅作未绑定遗留代码。
3. 最小 Compose 壳：按住说话 → 松手识别上屏 → LLM 回复流式 → TTS 播放。
4. 写「链路冒烟自动化脚本」（固定 3 句英文，统计延迟/识别率）。

**验收（可测量）**
| 指标 | 通过值 |
|---|---|
| 单轮往返（说→显字→LLM 首 token→TTS 起播） | p50 ≤ 3.5s，p90 ≤ 6s（中端真机，直连端点） |
| ASR 松手后转写上屏 | 依赖 MiMo 网络；无说话中 partial（与系统引擎时代指标不同） |
| 3 句固定句识别（WER 粗测） | 识别文本可读懂 ≥ 2/3 |
| 内存 | 会话页峰值 ≤ 350MB |

### M2 MVP（预计 3–5 周）

**任务**：按 01 §4 MVP 集合 + 03 对应页面落地；Room 建库（04 §6.1）；EV Prompt v1 + 标定回归集（04 §8）v0.1；会话崩溃恢复与录音分段。

**验收（功能冒烟主路径，E2E）**
```
打开App → 首次引导 → 配置直连LLM → 权限授权
→ 选话题「Hometown」自由对话 6 轮（每轮按住说话、看转写、听AI回复）
→ 结束会话 → 报告页出现四维分 + 至少 1 条错误/亮点条目
→ 点错误条回放录音 → 收藏进错题本 → 档案页出现今日时长与趋势点
```
- 上述主路径在 2 台 Android 真机（含 1 台低端、1 台 API 37）通过。
- 错题重练（VB-03）：错题 → 产出任务 → 判定通过 → 状态变更。
- EV 回归：标定集 8 条，逐维 |Δ分| ≤ 0.5 且方向不错（对既有 7.0 样例不打成 8.5）。

### M3 完整学习闭环（预计 3–5 周）

**任务**
1. 模拟口试 P1/P2/P3 + 完整流程（Part 2 计时与 cue card）。
2. barge-in（04 §4）；GR 影子跟读（GR-05）；逐句复盘 RP（句段索引）。
3. 服务器上线：05 §8 部署、设备注册、增量同步、冲突 LWW 验证；模式 B 代理可选开关。
4. HINT（EV-07）。

**验收**
| 场景 | 通过标准 |
|---|---|
| 双设备同步 | 手机练完 → 平板上看到会话统计与错题；改平板 → 手机次日拉回一致 |
| 离线→恢复 | 断网完成 1 次会话（提示离线，无 LLM 时允许仅本地文本复盘或保存草稿）→ 联网自动补传成功 |
| 冲突 | 两端同时改同一错题状态 → 结果 = 较新 `updatedAt`（可预期） |
| barge-in | AI 播报中说话 ≤ 400ms 内停止播放并进入聆听 |
| 代理模式 | 开启模式 B：客户端无 Key 完成对话；白名单外 model 被 403 |

### M4 发布打磨（预计 1–2 周）

- 双栏自适应与平板实机、深色模式对比度自查、TalkBack 冒烟。
- 录音清理策略与「导出/清除全部数据」双确认。
- targetSdk 37 合规自查表逐项过（04 §7.2）。
- 性能预算回归（Macrobenchmark 阈值）；应用签名与侧载包。
- 首次真实「S0 诊断 → 定 Stage」，产出首份与 7.5 的差距报告。

## 3. 全局验收标准（产品级）

| 编号 | 验收项 | 通过条件 |
|---|---|---|
| A-1 | 学习闭环完整 | 「对话→评测→纠错→回放→错题→重练→趋势」全链可用，无断点（03 §8 数据所有权成立） |
| A-2 | 延迟体验 | 满足 01 §5.1 预算（M1 后按预算卡回归） |
| A-3 | 离线可用 | 无网：本地录音与已保存轮次不丢，可回放/看历史；**不能**完成 ASR/TTS/LLM 对话（需 MiMo 网络） |
| A-4 | 评分可信 | 标定回归集全绿；用户可追溯每条评分证据句 |
| A-5 | 兼容 | API 26–37 实机矩阵通过；大屏双栏可用 |
| A-6 | 隐私默认安全 | 会话 wav 仅本地；识别/TTS 走用户配置的 MiMo；自有云同步显式开启且不存音频；Key 不明文落盘（04 §5.1/05） |
| A-7 | 服务器健康 | 2C2G 上压测 5 设备并发同步无错误；日备份成功 |

## 6. 主要风险登记册（汇总）

| # | 风险 | 概率/影响 | 缓解 | 归属里程碑 |
|---|---|---|---|---|
| R-1 | MiMo 端点/Key 不可用（替代原「无 GMS 系统 ASR」） | 中/高 | 设置页检查 URL/Key；SY-03 提示；会话本地可保存 | 持续 |
| R-2 | LLM 评分不稳定/偏宽 | 中/中 | 标定回归集 + promptVer 审计（04 §8） | M2 持续 |
| R-3 | ASR 误识使评分失真 | 高/中 | 可编辑转写 + 编辑后重评（03 §4.3） | M2 |
| R-4 | 个人时间不足、项目烂尾 | 中/高 | 每次 ≤10 分钟的设计 + 里程碑刻意收敛 | 全程 |
| R-5 | Compose/AGP 版本踩坑 | 低/中 | Studio 模板起步、版本冻结（04 §1.2） | M1 |
| R-6 | 服务器外网访问不稳定 | 低/中 | 同步频率低 + 离线优先；可切境内部署 | M3 |
| R-7 | 真实提分效果不达 7.5 | 中/高 | 以 S0 诊断与阶段完成标志做过程校验；S3/S4 前安排 1 次真题模考对照 | 持续 |

## 7. 结语（设计阶段收口）

- 本套文档（README + 01–06）构成 VoxCoach 的**设计基线**：功能、学习法、视觉、技术、运维五面齐备，且口径已互验。
- 下一步动作（M1）：以 `06 §2 M1` 为入口生成编码任务清单。任何一处与本文档冲突的实现决策，须回填修订本文档再动手，保持「文档即真源」。
- 个人目标提醒：**产品服务于雅思 7.5，而非反之** —— 里程碑若与备考节奏冲突，优先保证每周 ≥4 次、每次 ≤10 分钟的练习纪律（02 §5.1 周量建议）。
